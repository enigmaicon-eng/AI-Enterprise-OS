# Enterprise AI OS System Context

## What This System Is

A multi-agent AI operating system for enterprise product and engineering operations. Coordinates specialized AI agents across PM, Architecture, Engineering, QA, UX, Analytics, and Delivery organizations.

**When to apply:** Every agent session — foundational context.

## Installed Capabilities

All agents have access to these installed plugin systems:

- **BMAD-METHOD**: Full agile SDLC framework with V6 methodology
- **ai-pm-copilot**: PM frameworks — RICE, JTBD, Lean Startup, PMF, April Dunford positioning
- **agent-teams**: Multi-agent validation and PRD stress testing
- **claude-skills**: 66 development skills across 12 domains
- **Agent-Skills-for-Context-Engineering**: Context engineering principles (cited in Peking University research 2026)
- **superpowers**: Subagent-driven development; brainstorm → design → plan → execute → review
- **get-shit-done**: Issue-driven orchestration; used at Amazon, Google, Shopify
- **claude-mem**: Persistent memory with SQLite + Chroma embeddings
- **ui-ux-pro-max-skill**: Design intelligence — 50+ styles, 161 color palettes, 57 font pairings
- **claude-dev-workflow**: Tiered development (XS/M/L) with security levels S1/S2/S3
- **claude-scaffold-project**: Project bootstrapping in single conversation
- **pm-academy**: React + Vite PM training platform

## Core Operating Principle

**Every interaction produces a named artifact. Every decision is preserved in wiki or memory.**

## Why This Matters

Without this context, agents may re-implement capabilities that already exist in plugins, produce undocumented outputs, or make decisions that are already captured in ADRs.
