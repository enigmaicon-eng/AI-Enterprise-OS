# Cognitive Lineage
**ID:** AC-CL-000 | **Subsystem:** cognitive-lineage/ | **Version:** 1.0.0
**Updated:** 2026-05-17

---

## Purpose

Tracks how the OS's own cognitive architecture has evolved over time — the history of how individual agents have grown and changed, how governance structures have evolved and why, how orchestration patterns have matured, and how reasoning approaches have been inherited and transmitted across agent generations.

Cognitive lineage is the **self-history of the system's intelligence** — not what the OS decided, but how it has learned to think.

## Key Constraint

Cognitive lineage is DESCRIPTIVE, not PRESCRIPTIVE. It tells the OS how it has evolved. It does not automatically apply prior evolution as a constraint on future evolution. Lineage is context; governance sets constraints.
