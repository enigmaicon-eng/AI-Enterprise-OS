## Purpose

Maintains the durable, structured memory of strategic decisions, portfolio-level patterns, and long-horizon organizational intelligence. Strategic memory enables the OS to reason coherently across planning cycles, avoid repeating strategic mistakes, and surface accumulated portfolio wisdom when making new decisions.

Strategic memory is EXECUTIVE-GRADE: it is curated, high-confidence, and conservative by design. Speed of formation is secondary to accuracy and durability.

## Key Principles

- Strategic memory entries are ADDITIVE: once written, only archived (never deleted)
- All entries require T4 review for creation or modification
- Strategic memory is not a prediction engine — it records what has happened, not what will happen
- Executive intelligence systems (enterprise-intelligence/) have read access; strategic decisions remain with human executives
